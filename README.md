
# 📚 Projeto de Estudo em Java — Guia Interativo para Iniciantes

### Um projeto simples, direto e com o propósito de **ajudar colegas de classe** a compreender os fundamentos da linguagem Java de forma prática e acessível.

---

## 🧠 Sobre o Projeto

Durante os estudos para a prova do final do primeiro semestre, percebi que muitos colegas estavam enfrentando dificuldades para entender os conceitos básicos de Java. Pensando nisso, desenvolvi esse pequeno "aplicativo" em Java com a estrutura Maven, que funciona via terminal e oferece explicações passo a passo sobre os principais pilares da linguagem.

Este projeto não é apenas um menu com tópicos: ele é um **material didático interativo**, pensado do ponto de vista de um estudante, para estudantes — com linguagem clara, exemplos reais e uma progressão lógica que acompanha o desenvolvimento de quem está começando.

---

## 🛠️ Tecnologias Utilizadas

- **Java** (versão 8 ou superior)
- **Maven** para organização e gerenciamento de dependências
- **IDE sugerida:** NetBeans, IntelliJ IDEA ou Eclipse
- Interface: Terminal / Console

---

## 🎮 Como Funciona

Ao rodar o projeto, você verá um menu no terminal com as seguintes opções:

```java
System.out.println("1 - Estrutura básica e padrão");
System.out.println("2 - Variáveis");
System.out.println("3 - Sinais e cálculos");
System.out.println("4 - If e Else");
System.out.println("5 - While");
System.out.println("6 - Switch");
System.out.println("7 - Split");
System.out.println("8 - For");
System.out.println("10 - Finalizar");
```

Basta digitar o número da opção desejada para visualizar a explicação de cada conceito. Cada item do menu chama uma classe diferente, contendo conteúdos explicativos, exemplos de código e comentários que ajudam a entender **o que está sendo feito e por quê**.

---

## 💡 O Que Você Vai Aprender

Cada seção aborda um tema específico e fundamental da linguagem Java, como:

### ✅ Estrutura Básica
- Como estruturar um programa Java
- `public static void main`
- Organização do código

### ✅ Variáveis
- Tipos primitivos (`int`, `double`, `char`, `String`)
- Declaração e inicialização
- Diferença entre `char` e `String`

### ✅ Operadores e Cálculos
- Operadores matemáticos e lógicos
- Como realizar somas, subtrações, multiplicações, etc.

### ✅ Estruturas Condicionais
- `if`, `else if`, `else`
- `switch` com `case` e `default`

### ✅ Laços de Repetição
- `while`
- `for`
- Aplicações práticas

### ✅ Funções como `split`
- Manipulação de Strings
- Separação e leitura de dados

Cada um desses módulos conta com explicações simples e diretas, com base em situações reais e experiências pessoais.

## 🎯 Objetivo Pedagógico

Este projeto não visa ser um material técnico ou formal, mas sim uma **ferramenta de apoio para revisão e fixação de conteúdo**.

Ideal para:
- Estudantes que estão começando na linguagem Java.
- Quem precisa revisar antes de uma prova.
- Pessoas com dificuldade em entender a documentação oficial ou aulas mais teóricas.
- Apoio em grupos de estudo.

## 🚀 Como Executar

cd java-guia-estudo
